# Reproducing the study

From the extracted project directory, run the following command.

```sh
Rscript --vanilla scripts/reproduce.R
```

The entry point obtains the three pinned source files, checks their digests, rebuilds the long-form review data, runs the calibration and ordering checks, refits the models, evaluates sensitivity and writes both figures in PNG and PDF format. Existing source downloads in `data/raw/` are verified before use. The script runs in fresh R processes. The ordering bootstrap uses one worker on Windows and up to three on systems supporting process forks. The analysis scripts set the simulation seeds.

Install the required R packages in a writable R library. R needs Cairo support for vector figure export.

```r
install.packages(c("digest", "igraph", "readxl", "Matrix", "pbivnorm", "statmod",
                   "mirt", "ggplot2", "ragg", "systemfonts", "systemfonts"))
```

The numerical and graphics checks were run with R 4.6.0 on 64-bit Apple silicon, Darwin 25.4.0, with C.UTF-8 collation. The direct package versions and graphics comparison dependencies are recorded in [environment.csv](environment.csv). R reported Cairo 1.17.6 and libpng 1.6.56. Package versions, operating system and available fonts can affect raster rendering.

The verification directory contained only copies of `R/*.R`, the R scripts in `scripts/`, and the three raw data files. The data preparation scripts verified the cached 1.5.1 release files `NIH.rda` and `AIBS.rda` and the Zenodo workbook `snsf_individual_votes.xlsx` against their pinned SHA-256 digests. The clean rerun used these cached inputs and exercised all processing steps after retrieval. The preparation scripts retained their source URLs for fresh downloads.

I invoked `Rscript --vanilla <rerun-directory>/scripts/reproduce.R` from outside the clean directory. All 11 component scripts completed. The criteria simulation recovered a cross-review loading of 0.597 for a target of 0.600. The fixed-parameter TGI checks, independent ordering enumeration and continuous-score accuracy bound all passed. The criterion analysis used 999 proposal bootstrap replicates. The ordering analysis used 400 proposal and 400 joint proposal and reviewer weight replicates in each of 11 pools.

The clean run reproduced every cell and every byte of both derived data CSVs, all seven audit CSVs and all eight result CSVs. The original figures matched in every decoded pixel, across 1,800 × 840 pixels for Figure 1 and 2,080 × 1,794 for Figure 2. Both scripts also produced vector PDFs.

## Full rerun with the dimensionality diagnostic

I also rebuilt the revised study in an empty directory using only the R scripts and the three checksum-verified public inputs. All 13 component scripts completed. Both derived CSVs, seven audit CSVs and nine results CSVs were byte-identical to the study files. This includes all 20 residuals and interval estimates in the two US datasets. The two figures matched in every decoded pixel. In simulated data the diagnostic estimated excess innovation agreement of 0.009 when the generating value was zero and 0.235 when it was 0.230. [Diagnostic assumptions and interpretation](../methods/dimensionality.md)

To compare two runs in the same environment, install the R package `png` and run the following command. The comparison checks CSV inventory, dimensions, names and values, then both decoded PNGs.

```sh
Rscript --vanilla scripts/check_reproduction.R /path/to/reference /path/to/rerun
```
